## Deskripsi
Program ini merupakan aplikasi berbasis console yang dibuat menggunakan bahasa C untuk mengelola stok produk dan transaksi penjualan kantin kampus.

## Fitur
1. Menampilkan daftar produk.
2. Menambahkan produk baru.
3. Mengubah harga dan stok produk.
4. Melakukan transaksi penjualan.
5. Menambahkan stok produk.
6. Mencari produk berdasarkan nama.
7. Mengurutkan produk berdasarkan harga dan jumlah terjual.
8. Menampilkan laporan penjualan.
9. Mengecek stok produk yang kurang dari 5.

## Penerapan Array
Program menggunakan array satu dimensi untuk menyimpan harga, stok, dan jumlah produk terjual. Array karakter dua dimensi digunakan untuk menyimpan nama produk. Kapasitas maksimal adalah 50 produk.
